# Colony Power – Electricity Billing App for Colonies (Nepal)

**Colony Power** is a free electricity billing web app for colonies, rented houses and shared meters in Nepal. The administrator records monthly meter readings, the app calculates every consumer's bill by **Nepali (BS) month**, tracks payments, dues and advances, and each consumer can log in to see their own bill.

**Open the app:** https://ry978926-lang.github.io/Colony-Power/

Searching for *Colony Power*, *Colony Power Billing*, *colony electricity billing Nepal* or *Janakpurdham electricity bill app* should lead here.

## Features

- Monthly meter readings with automatic unit and bill calculation
- Rate per unit set separately for each BS month and year
- Optional fixed monthly charge – choose which consumers pay it
- Payments, dues and advance tracking (oldest due month is paid first)
- Private dashboard for every consumer (current amount, due amount, history)
- Main-meter record with total to be paid and total paid by consumers
- Notes with photos, and consumer photos, stored in the database
- English and Nepali (नेपाली) language, light and dark mode
- Installable on your phone like an app (PWA)
- Database storage usage and photo sizes at a glance (admin)

## Built with

Plain HTML, CSS and JavaScript (single page), [Supabase](https://supabase.com) for the secure database and login, hosted on GitHub Pages.
